# 错误场景手动测试

本目录集中验证编译期 / 运行时错误是否能被插件正确捕获并展示，且不导致 Obsidian 崩溃。

在 **阅读模式** 下依次打开下列笔记。

## 用例

- [[01 - 语法错误]] — 本块 `<script>` 语法错误，应显示编译错误面板
- [[02 - 导入文件语法错误]] — 导入的 TS 文件有语法错误，应显示编译错误面板
- [[03 - setup报错]] — `setup` 同步抛错，应显示错误（不渲染组件或错误面板）
- [[04 - 点击按钮报错]] — 组件先渲染，点击后下方出现「运行时错误」面板
- [[05 - 异步setup报错]] — 顶层 `await` 后抛错 / `Promise.reject`，应显示错误
- [[06 - 导入组件setup报错]] — 子组件 `setup` 抛错，应显示错误

## 检查清单

- [ ] 语法错误：显示可读编译错误，不崩溃
- [ ] 导入文件语法错误：错误信息指向被导入文件，不崩溃
- [ ] setup 报错：显示错误面板，不崩溃
- [ ] 点击按钮报错：按钮可见，点击后组件下方出现「运行时错误」
- [ ] 异步 setup 报错：短暂等待后出现错误面板（非整块空白崩溃）
- [ ] 导入组件 setup 报错：父块挂载失败或显示子组件相关错误
